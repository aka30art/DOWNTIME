GOVERNANCE / CONTROL PLANE

System controls

Review the safeguards governing this isolated configuration workspace.

READ ONLY
Authentication boundary
Server-side access is restricted to DEV with OWNER tier and DEVACC. Other tiers are denied regardless of client visibility.
Draft and publish separation
Draft saves create versioned snapshots. Publishing requires an explicit action and a matching version check.
Recovery controls
Historical snapshots can be restored as a new draft. Restore does not publish automatically.
Operational isolation
This control plane does not write to tracker operational records, user accounts, active shifts, reports or live application settings.
