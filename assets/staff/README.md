# DOWNTIME STAFF IMAGE LIBRARY

Permanent original-resolution staff photographs belong in `assets/staff/originals/`, named `jan.jpg`, `mick.jpg`, `gigi.jpg`, `daz.jpg`, and `shayne.jpg`.

**Upload instructions:** Upload original files without resizing, recompressing, or cropping. Then mark the corresponding `available` value true in `staff-image-library.js`. The app will prefer the permanent image and automatically fall back to existing Central photo storage if the image fails. Staff portraits on roster and crew switchboard share the same resolver.

Original image binaries are not included yet; separate original staff photos are required. Existing secure photo upload/storage remains unchanged.
